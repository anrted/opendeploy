# Roadmap

OpenDeploy is currently an early alpha foundation.

## Alpha

- [ ] Critical-action confirmation flow
- [ ] Frontend migration to TypeScript
- [x] Embed the production SPA in the Core binary
- [ ] Integration tests on supported Linux distributions
- [x] Secure installer and upgrade workflow

## Beta

- Complete PHP version management
- Node.js runtime management
- Git deployment workflow
- PostgreSQL repository implementations
- Backup and restore

## Later

- Remote Agents with mutual TLS
- Signed third-party module distribution
- Multi-server orchestration

Roadmap items are directional and do not represent release commitments.
